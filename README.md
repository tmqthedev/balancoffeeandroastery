\# ☕ Balan Coffee \& Roastery - AWS Workshop v2



Modernizing the existing Balan Coffee web application with AWS services.



\---



\## 🚀 Getting Started



\### 1. Clone the repository



```bash

git clone <repository-url>

cd balan-coffee

```



\### 2. Switch to the development branch



```bash

git checkout aws-workshop-v2

git pull origin aws-workshop-v2

```



\### 3. Install dependencies



```bash

npm install

```



\### 4. Setup environment



```bash

cp .env.example .env

```



\### 5. Start the application



```bash

npm run dev

```



Done! 🎉
